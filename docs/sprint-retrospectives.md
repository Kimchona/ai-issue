# 스프린트 회고

> 저장소의 마일스톤을 기준으로 완료했다고 가정해 작성한 회고 초안입니다.

## 스프린트 1 — 데이터 준비와 기초 통계

- **상황 (S):** 분석에 사용할 데이터와 기본 통계 결과가 필요했다.
- **목표 (T):** 데이터 출처·스키마를 정리하고 전처리 및 기초 통계를 완료한다.
- **실행 (A):** 결측치와 이상치를 점검하고 자료형을 정리한 뒤 기술통계량을 산출했다.
- **결과 (R):** 분석 가능한 데이터 기준선을 마련했다. 다음에는 전처리 규칙과 제외 기준을 더 일찍 합의한다.

## 스프린트 2 — 분석과 결과 공유

- **상황 (S):** 준비된 데이터에서 질문에 답하고 결과를 재현 가능하게 전달해야 했다.
- **목표 (T):** 통계 분석·시각화를 마치고 실행법과 해석을 문서화한다.
- **실행 (A):** 분석 질문에 맞춰 그룹을 비교하고 차트와 결과 해석, 실행 절차를 정리했다.
- **결과 (R):** 결과를 공유할 수 있는 형태로 마무리했다. 다음에는 분석 초기에 검증 기준과 한계를 명시한다.
